## Описание проекта

**Education Journal** — веб-приложение для управления электронным журналом успеваемости студентов. Система позволяет преподавателям вести записи оценок и посещаемости, студентам просматривать свои результаты, а администраторам управлять структурой учебного заведения.

### Основной функционал

- **Система аутентификации** — вход по email и паролю с JWT токенами
- **Управление студентами и группами** — создание групп и управление студентами
- **Ввод оценок** — интерактивный ввод оценок студентов в таблице
- **Учет посещаемости** — отслеживание присутствия студентов на занятиях
- **Профили пользователей** — разные уровни доступа (администратор, преподаватель, студент)
- **Просмотр рейтингов** — просмотр успеваемости студентов по предметам

## Установка и запуск

### Требования

- Python 3.8 или выше
- PostgreSQL 12 или выше
- pip (менеджер пакетов Python)

### Пошаговая инструкция

#### 1. Клонирование репозитория

```bash
git clone https://github.com/Katronicsl/education_journal.git
cd education_journal
```

#### 2. Создание виртуального окружения

```bash
# Linux/macOS
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

#### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

#### 4. Настройка базы данных PostgreSQL

```bash
# Создание базы данных
createdb postgres

# Или через psql
psql -U postgres
CREATE DATABASE postgres;
```

#### 5. Конфигурация приложения

Отредактируйте файл `config.py` для настройки подключения к базе данных:

```python

SQLALCHEMY_DATABASE_URI = "postgresql+psycopg2://postgres:postgres@localhost:5432/postgres"

```

#### 6. Запуск приложения

```bash
python run.py
```

Приложение будет доступно по адресу: **http://localhost:5001**

## Безопасность

- **Аутентификация:** JWT токены, сохраняются в cookies
- **Хеширование паролей:** Bcrypt с солью
- **Переменные окружения:** Используйте переменные окружения для секретных ключей

### Обязательные переменные окружения

```bash
export SECRET_KEY="ваш-очень-длинный-секретный-ключ-здесь"
export JWT_SECRET_KEY="ваш-jwt-секретный-ключ-здесь"
export FLASK_ENV="production" 
export DATABASE_URL="postgresql+psycopg2://user:password@host:port/dbname"
```

## Основные модели данных

### User (Пользователь)
- ID, фамилия, имя, отчество
- Email, пароль (хеш)
- Роль (администратор, преподаватель, студент)
- Дата создания и обновления

### Subject (Предмет)
- ID, название
- Изображение/иконка

### Lesson (Урок)
- ID, название, дата
- Связь с предметом и группой

### Grade (Оценка)
- Студент, предмет, дата
- Значение оценки

### Attendance (Посещаемость)
- Студент, урок, дата
- Статус (присутствует, отсутствует, отсутствует по уважительной причине)
