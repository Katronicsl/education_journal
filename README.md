## 📋 Описание проекта

**Education Journal** — веб-приложение для управления электронным журналом успеваемости студентов. Система позволяет преподавателям вести записи оценок и посещаемости, студентам просматривать свои результаты, а администраторам управлять структурой учебного заведения.

### Основной функционал

- **Система аутентификации** — вход по email и паролю с JWT токенами
- **Управление студентами и группами** — создание групп и управление студентами
- **Ввод оценок** — интерактивный ввод оценок студентов в таблице
- **Учет посещаемости** — отслеживание присутствия студентов на занятиях
- **Профили пользователей** — разные уровни доступа (администратор, преподаватель, студент)
- **Просмотр рейтингов** — просмотр успеваемости студентов по предметам

## 🚀 Установка и запуск

### Требования

- Python 3.8 или выше
- PostgreSQL 12 или выше
- pip (менеджер пакетов Python)

### Пошаговая инструкция

#### 1. Клонирование репозитория

```bash
git clone https://github.com/Katronicsl/education_journal.git
cd education_journal
```

#### 2. Создание виртуального окружения

```bash
# Linux/macOS
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

#### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

#### 4. Настройка базы данных PostgreSQL

```bash
# Создание базы данных
createdb postgres

# Или через psql
psql -U postgres
CREATE DATABASE postgres;
```

#### 5. Конфигурация приложения

Отредактируйте файл `config.py` для настройки подключения к базе данных:

```python
# Для разработки (по умолчанию)
SQLALCHEMY_DATABASE_URI = "postgresql+psycopg2://postgres:postgres@localhost:5432/postgres"

# Для продакшена установите переменную окружения
export DATABASE_URL="postgresql+psycopg2://user:password@host:port/dbname"
```

#### 6. Запуск приложения

```bash
python run.py
```

Приложение будет доступно по адресу: **http://localhost:5001**

## 📊 Основные модели данных

### User (Пользователь)
- ID, фамилия, имя, отчество
- Email, пароль (хеш)
- Роль (администратор, преподаватель, студент)
- Дата создания и обновления

### Course (Дисциплина)
- ID, название, описание
- Часы и кредиты

### Subject (Предмет)
- ID, название
- Изображение/иконка

### Lesson (Урок)
- ID, название, дата
- Связь с предметом и группой

### Grade (Оценка)
- Студент, предмет, дата
- Значение оценки

### Attendance (Посещаемость)
- Студент, урок, дата
- Статус (присутствует, отсутствует, отсутствует по уважительной причине)

## 🔄 API Endpoints

### Аутентификация
- `POST /auth/login` — вход в систему
- `POST /auth/register` — регистрация преподавателя
- `POST /auth/logout` — выход из системы

### Студент
- `GET /student/` — главная страница студента
- `GET /student/grades` — оценки студента
- `GET /student/attendance` — посещаемость

### Преподаватель
- `GET /teacher/` — главная страница преподавателя
- `GET /teacher/groups` — мои группы
- `POST /teacher/api/update_grades` — обновление оценок
- `POST /teacher/api/update_attendance` — обновление посещаемости

### Администратор
- `GET /admin/` — панель администратора
- `GET /admin/groups` — все группы
- `GET /admin/users` — все пользователи
- `POST /admin/api/*` — различные API методы

## 🗄️ База данных (PostgreSQL)

### Подключение к БД

```bash
# Подключение к локальной БД
psql -U postgres -d postgres

# Выполнение запросов для проверки таблиц
\dt  # список таблиц
\d users  # описание таблицы
```

### Пример создания таблицы users

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    last_name VARCHAR(100) NOT NULL,
    first_name VARCHAR(100) NOT NULL,
    middle_name VARCHAR(100),
    email VARCHAR(120) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    role VARCHAR(50) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 🐛 Решение проблем

### Ошибка подключения к БД

```
Error: could not connect to server: Connection refused
```

**Решение:**
- Проверьте, что PostgreSQL запущен: `pg_isready`
- Проверьте учетные данные в `config.py`
- Убедитесь, что база данных создана

### Ошибка при импорте модулей

```
ModuleNotFoundError: No module named 'flask'
```

**Решение:**
```bash
pip install -r requirements.txt
```

### Ошибка JWT токена

**Решение:**
- Проверьте, что `SECRET_KEY` и `JWT_SECRET_KEY` установлены в `config.py`
- Очистите cookies браузера
- Перезагрузитесь и войдите заново
